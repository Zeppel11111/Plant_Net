# Plant_Net PCB 扩展板 Pinout

> 适用对象：STM32F103C8T6 最小系统板（Blue Pill）、ESP-01S（ESP8266）、
> 现成的 JSM485ESA 自动收发 RS485 模块、塔石温湿度光照传感器。
>
> 本表以当前固件为准（2026-09-11）。PCB 采用“扩展板放排母、现有模块直插”的方式时，
> 请以各模块丝印的引脚名而不是排针物理方向连线，避免不同厂商板子的排针朝向差异。
> ESP32-CAM 是独立的网络节点，不安装在本扩展板上。

## 1. 连接关系总览

```text
TAS_GZ  <-- A/B -->  JSM485ESA  <-- UART2 -->  STM32F103C8T6
                                                |
                                             UART3
                                                |
                                             ESP-01S  -- Wi-Fi/TCP --> 服务器

ESP32-CAM（Micro-USB 独立供电/烧录） --------------------- Wi-Fi/TCP --> 服务器
```

ESP32-CAM 当前**没有**与 STM32 的直连数据线，也不接入本扩展板。它通过 Micro-USB
独立供电、烧录；运行时经 Wi-Fi/TCP 直接推流至服务器。

## 2. STM32F103C8T6 引脚统计

| STM32 引脚 | 外设/信号 | 当前用途 | PCB 网络名建议 | 状态 |
|---|---|---|---|---|
| PA2 / PA3 | USART2_TX / USART2_RX | RS485/Modbus（9600, 8N1） | `RS485_TX` / `RS485_RX` | 已用 |
| PA9 / PA10 | USART1_TX / USART1_RX | 日志、VOFA 调试串口（115200, 8N1） | `DBG_TX` / `DBG_RX` | 已用 |
| PB10 / PB11 | USART3_TX / USART3_RX | ESP-01S AT 指令与 TCP 上行（115200, 8N1） | `ESP_TX` / `ESP_RX` | 已用 |

### STM32 已用 IO 小结

| 分类 | 数量 | 引脚 |
|---|---:|---|
| 扩展板实际布线 | 6 | PA2、PA3、PA9、PA10、PB10、PB11 |
| 仅保留在 Blue Pill 本体 | — | PC13、PD0、PD1、PB6、PB7、PA13、PA14、NRST、BOOT0 |

上述“仅保留在 Blue Pill 本体”的引脚仍由模块自身使用或保留，但扩展板不需要为它们放置
端子、排针或走线。其余 GPIO 在当前固件中未使用，未来需要时再单独加扩展接口。

## 3. PCB 接插件/排母定义

### J0 — Blue Pill 主控板排母（2 x 20，2.54 mm）

扩展板应为 Blue Pill 的两排 20 针排针分别放置 2 x 20 排母；封装方向以主控板 USB 接口、
复位按键和板上丝印为准。下表列出必须在扩展板上接出的主控网络。

| Blue Pill 丝印 | 扩展板去向 | 说明 |
|---|---|---|
| 3.3V | `+3V3` | 主控逻辑供电；不要作为两块 Wi-Fi 板的唯一电源 |
| G / GND | GND 平面 | 与所有模块共地 |
| PA2 | J2 TXD/DI | USART2_TX → RS485 模块 |
| PA3 | J2 RXD/RO | USART2_RX ← RS485 模块 |
| PA9 | J4 `DBG_TX` | 日志输出 |
| PA10 | UART 测试点 `DBG_RX` | 日志输入/VOFA 双向调试 |
| PB10 | J1 RXD | USART3_TX → ESP-01S |
| PB11 | J1 TXD | USART3_RX ← ESP-01S |

### J1 — ESP-01S 排母（2 x 4，3.3 V 逻辑）

| ESP-01S 丝印 | 扩展板连接 | 说明 |
|---|---|---|
| VCC | `+3V3_ESP` | 独立、足够电流的 3.3 V 电源 |
| GND | GND | 与全部模块共地 |
| TXD | PB11 / `ESP_RX` | ESP-01S → STM32，串口交叉 |
| RXD | PB10 / `ESP_TX` | STM32 → ESP-01S，串口交叉 |
| EN / CH_PD | `+3V3_ESP` 上拉 | 正常运行必须为高 |
| RST | `+3V3_ESP` 上拉，建议接复位按键 | 低电平复位模块 |
| GPIO0 | 上拉；可用跳帽接 GND | 仅烧录 AT 固件时拉低并复位 |
| GPIO2 | 上拉/悬空 | 启动配置脚，不作普通 IO 使用 |

### J2 — RS485 自动收发模块排母

| JSM485ESA 丝印 | 扩展板连接 | 说明 |
|---|---|---|
| TXD / DI | PA2 / `RS485_TX` | MCU 发往 485 总线 |
| RXD / RO | PA3 / `RS485_RX` | 485 总线收至 MCU |
| VCC | `+3V3` 或模块规定电压 | 下单前确认所购模块的供电和 3.3 V 逻辑兼容性 |
| GND | GND | MCU 与模块共地 |
| A / B | J3 的 A / B | 差分总线；若无通信，优先对调 A/B 验证 |

### J3 — 塔石传感器 RS485 与供电端子

| 端子网络 | 连接对象 | 说明 |
|---|---|---|
| `RS485_A` | 传感器 A | 与 J2 A 同网 |
| `RS485_B` | 传感器 B | 与 J2 B 同网 |
| `SENSOR_V+` | 传感器电源正 | 按传感器铭牌电压供电，不与 3.3 V 假定等同 |
| `SENSOR_GND` | 传感器电源负 | 与系统地按供电方案正确连接 |

### J4 — UART 日志排针（建议 1 x 4）

| 引脚 | 网络 | 用途 |
|---|---|---|
| 1 | `+3V3` | 串口模块参考电平 |
| 2 | GND | 地 |
| 3 | `DBG_TX` / PA9 | STM32 日志输出 |
| 4 | `DBG_RX` / PA10 | STM32 日志输入 |

此接口只用于 USB-TTL/VOFA 日志，不包含 SWD、NRST 或 BOOT0。

## 4. 电源与布局硬约束

| 电源网络 | 负载 | PCB 建议 |
|---|---|---|
| `+3V3` | STM32、ESP-01S、I2C、RS485 逻辑 | 由主控最小系统板或独立稳压提供；以实际供电方案为准 |
| `SENSOR_V+` | RS485 传感器 | 按实物传感器铭牌确定，不要默认接 3.3 V |

- 本板只做模块互连，**不重复设计** ESP32-CAM 的 5 V/3.3 V、下载与摄像头接口；其 Micro-USB
  供电器须能承受 Wi-Fi 与摄像头工作电流。
- STM32、ESP-01S、RS485 模块必须共地。ESP-01S 串口是 3.3 V 逻辑，不能接 5 V TTL。
- RS485 A/B 靠近端子走线；若传感器线较长，预留 120 Ω 终端电阻焊盘和 TVS 防护位置。
- ESP32-CAM 天线区域下方/前方避免铺铜、走线和金属遮挡。
