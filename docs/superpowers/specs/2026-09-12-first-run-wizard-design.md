# Plant_Net 首次配置向导设计

## 目标

让刚从 GitHub 获取项目的 Windows 使用者只填写三项本机信息：MySQL 密码、热点名称和热点密码。完成后即可分别烧录 STM32 与 ESP-CAM；无需手动复制或同步配置文件。

## 入口与交互

项目根目录新增 `首次配置.bat`，可在资源管理器中双击运行。它调用同目录下的 Python 向导，不要求使用者理解命令行参数。

向导按顺序询问：

1. MySQL 密码（输入时不回显）；
2. Windows 移动热点名称；
3. Windows 移动热点密码。

空值会被拒绝，异常会在窗口中说明原因，并暂停窗口以便用户读取。

## 生成文件

向导从公开模板生成本机私有配置：

- `Flask_TCP/local_config.py`：写入 MySQL 密码；
- `config/net_config.h`：写入热点名称、热点密码和备用服务器地址；
- `STM32/Core/Inc/net_config.h`：由统一源配置复制生成；
- `ESP-CAM/CameraWebServer/net_config.h`：由统一源配置复制生成。

上述私有配置已被 Git 忽略，向导不会修改公开模板。

## 网络策略

向导不询问服务器 IP，备用值固定为 `192.168.137.1`，这是 Windows 移动热点常见默认地址。固件仍首先通过 DHCP 默认网关寻找服务器；因此在默认地址被系统网络环境改变时，设备不依赖该备用值也能连接。

## 替换范围

删除旧的命令行配网工具，以新的资源管理器入口作为唯一面向新用户的配置工具。不会改变端口、STM32/ESP-CAM 源码的连接逻辑或烧录方法。

## 验收

在未生成本地配置的副本目录中双击 `首次配置.bat`，填写三项信息后，四个目标文件均被生成；两份固件配置内容一致，MySQL 配置包含填写的密码。随后窗口给出“启动 Flask 服务、编译烧录 STM32、上传 ESP-CAM”的明确提示。
