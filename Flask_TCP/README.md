# 植物环境监测 数据服务器（Flask + MySQL）

## 这是什么
接收 STM32 设备上传的环境数据（TCP 端口 9000），存进 MySQL，
并提供网页（端口 8080）查看最新数据和历史记录。

数据行格式（设备 → 服务器，每行以换行结尾）：
```
dev01,268,391,440      ← 设备ID,温度x10,湿度x10,光照
268,391,440            ← 不带设备ID也兼容（自动记为 dev01）
```

## 首次运行（三步）
1. **启动 MySQL**：任务管理器 → 服务 → MySQL80 → 启动（或管理员 PowerShell 执行 `net start MySQL80`）
2. **装依赖**：PyCharm 底部 Terminal 里执行 `pip install -r requirements.txt`
3. **配置并运行**：复制 `local_config.example.py` 为 `local_config.py`，填写
   `MYSQL_PASSWORD`；然后运行 `server.py`。`local_config.py` 不会提交，库和表会自动创建。

## 怎么验证
- 看到控制台打印 `[OK] 数据库已就绪` 和 `TCP 接收服务已启动`
- 浏览器打开 `http://127.0.0.1:8080`
- 给板子上电：设备会自动连 9000 端口上传，控制台每秒打印 `[收到] ...`，
  网页每 5 秒刷新出数据

## 常见问题
| 现象 | 原因 |
|---|---|
| 报 `连不上 MySQL` | MySQL80 服务没启动，或密码填错 |
| 网页打开但没数据 | 设备没连上（看它串口日志），或防火墙拦了 9000 |
| 控制台报 `无法解析的行` | 收到非数据内容，忽略即可（或查设备协议） |
